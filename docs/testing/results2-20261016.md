All new ordinary paths run from startup through a natural finish and the full
ending hold. Every callback collects a complete recipient snapshot for every
seat and checks the room has no fault. The ending cases cover Assault structure
and timer decisions, Annihilation elimination, Classic elimination, sudden
death and a draw, plus Conquest VP victory. A host termination check uses the
actual host command after ordinary ticks and recipient delivery.

The exact wire shapes and prototype line references are in
[ordinary-results.md](../contracts/ordinary-results.md). Hosted Horde result
parts remain guarded, World stays closed, and NET-78 is excluded.

Validation uses Rust 1.99.0 from `rust/`, a free S1-S3 flock and its matching
slot target directory, `MemoryMax=6G`, zero swap and four build jobs. Tests use
`ci-test` to keep compilation below the cap. Only affected packages and focused
tests are run locally; hosted CI owns the complete suite. The PR body records
the final-head commands and results.
