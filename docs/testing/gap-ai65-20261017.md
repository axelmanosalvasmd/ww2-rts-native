# GAP-AI65 outcome comparison

This is case (b) from the GAP-AI65 task. The design fragment records the
independent-stream `differs` decision and the criteria chosen before execution.
`room_ai::seeded_tests` is registered in `room_ai.rs`; no new registration is
needed. The existing native-only replay matrix remains useful but does not
establish JavaScript input equality.

The six `ai65_*_against_pinned_javascript` tests are ignored by default because
they require an external clean prototype checkout and Node. Explicitly run
with the shared Cargo slot protocol and these environment variables:

```text
WW2_AI65_REFERENCE=/absolute/path/to/clean/reference/ww2-rts
WW2_AI65_NODE=/absolute/path/to/node
cargo nextest run --locked --cargo-profile ci-test -j4 -p ww2-server --lib --run-ignored ignored-only -E 'test(against_pinned_javascript)'
```

The reference must resolve exactly to e4e579a838aabae3b1d9dadbc17a0a87147bc52d.
`harness/ai65-outcomes.mjs` checks that pin and tracked cleanliness before and
after running the original `playMatch` twice. It writes no fixture files.
Each test also repeats the compared native profile, checking complete input,
admission, brain, save and outcome equality. Effective startup receipts compare
the authored map and normalized mode, roster, factions, AI roles/levels,
army, tech, logistics, supply, sandbox and initial weather. Random spawn
positions and independent RNG state are deliberately excluded.

The seed-617 case reuses the prototype's capture, fight, spending and finish
predicates with this explicit options-off, supply-off profile. It does not
claim to reproduce the defaults of the prototype test.js invocation. Native
recipient delivery continues for eight ticks after natural victory.
The 3,600-tick cases compare coarse outcome categories, not statistical balance.
Actual winner, tick, unit counts, scores, losses and spending are printed for
both engines. World execution remains deferred for R1.
