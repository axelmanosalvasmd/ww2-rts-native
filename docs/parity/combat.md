## Existing limitations

- Live matches are not reproducible: the server never seeds `Math.random` (its only call picks a weather seed, server.js:381), and combat rolls draw from it (shared/sim.js:772, 4171). Only harnesses that replace it (`playMatch` with a seed, tools/balance.mjs, tests) replay a match.
- The AI and combat share one random stream, so any change in how often the AI draws shifts every later combat roll (shared/ai.js has 3 `Math.random` calls).
- Physical salvos still draw two `Math.random` values per shell in the `g.salvos` loop and discard them (shared/sim.js:5625-5626).
- An attack order given only to unarmed units (medics, trucks) answers 'queueFull', which the client shows as "This unit already has 8 queued orders" (shared/sim.js:3502, 3510; client/availability.js:20-23).
- A manual barrage checks only the ability range, not the weapon's minimum range, so mortars, howitzers, rocket launchers and destroyers can barrage their own feet; autocast does respect it (shared/sim.js:5420 vs 3889).
- A salvo fire-at on open ground never clears, so a Shift-queued order behind it waits forever (DESIGN.md:944-948).
- Kill bounty is 20% of `cost` even in Classic, where the unit was paid at `classicCost` (shared/sim.js:5697 vs 391).
- Anti-air damage gives XP but no kill bonus (shared/sim.js:2249).
- Smoke clouds take ids from the unit id counter, so a smoke ability shifts later unit ids (shared/sim.js:3624, 5274).
- Ties in unordered spatial queries (nearest threat in `threatFor`, most hurt squad in `healWounded`, separation) resolve by grid bucket order (shared/grid.js:60-61, 76-107).
- The fog pass's sight walk (`fogLos`) checks only the sight bit, not the woods depth rule `los` applies, so the fog shows ground behind more than three woods cells as seen while a unit standing there is not seen (shared/sim.js:4502-4511 vs 2806). The Rust port keeps this.
- `teamSees`, used to validate orders on spots, ignores the 6 m rule, high ground, garrison vision and rain, so it can disagree with unit visibility and the drawn fog (shared/sim.js:1747-1751 vs 4548).
- Medics notice new wounds only every 10 ticks (shared/sim.js:4950).
- Terrain changes inside fog still reach every client (DESIGN.md:1511).
- Formation facing: queued plan lines do not draw facing, the AI never sets facing, the minimap has no facing drag, and an automatic cover shift cancels the facing (DESIGN.md:2338).
- No JS test pins veterancy effects, flame rules, Suppressive Fire multipliers, Ura! suppression immunity, commando camouflage, gun-pit range or tank-destroyer behavior.
