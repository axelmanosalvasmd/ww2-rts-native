# Modes and match flow (MODE)

Source: `reference/ww2-rts` at e4e579a. Evidence paths are relative to that folder. Units: seconds, metres, MP; one cell is 2 m; one tick is 1/20 s.

Conventions used below:

- There are seven mode kinds. Conquest is the default and runs with no mode object (`g.mode` is undefined); every other kind sets `g.mode.kind`. Code that tests `!g.mode` means Conquest.
- "Skirmish modes" are Conquest, Assault, Annihilation and Horde (`isSkirmishBaseMode`, `shared/sim.js:385`). "Construction modes" are Classic and World (`isConstructionMode`, `shared/sim.js:384`).
- "Seeded parity run" means the JS `playMatch` harness (`shared/ai-schedule.js:47-72`), which replaces `Math.random` with a seeded generator for the whole match, creation included. The native run uses the same map, names, teams, factions, options and seed, and must give the same winner, `endReason`, `endTick` and `endAt`.
- Economy, buildings and tiers are BASE rows; this section references them instead of repeating them.

## Existing limitations

- **Tutorial has no fail state.** Only finishing step 9 ends it; a player who loses every unit stays in a running match. `shared/tutorial.js:109-117`, `shared/sim.js:5770`.
- **Tutorial income comes from the Assault attacker base (5 MP/s)** because Tutorial sets no defender team. This looks accidental. `shared/sim.js:5751`.
