It returns `WorldRecipientMetadata`: a `WorldPanel`, typed observed `RecipientLists` and optional `KnownWorldMap`. `to_json()` supplies the corresponding reference fields for comparison. It does not emit a complete snapshot envelope or change an external contract.

The method requires represented World mode and a real commander seat. Immutable geography, current regions/nodes/stations, wallets, units, production queues, visibility and remembered buildings come from their canonical owners. Wreck display facts come from Environment and are retained only after actual observation; hidden rows are not completed from live state. Current region queries remain the existing borrowed `world_region_at` and `world_region_index` methods.

The method stages only the existing WorldMemory component. It reuses the binding-checked collector, shared region/wreck selectors and pure map/panel/list projections. A failure leaves canonical memory, Fog, journal and pending terrain unchanged. Terrain send cursors, route application, live route caches, delivery/version acknowledgment and all-seat publication remain separate.

Known geography follows accepted team cell order, including ordered material rows and the source's unknown dots/zero heights. Allied spawns alone are included. Nodes use known-cell or reveal selection; stations require a known cell. The optional station field follows the authored rails fact used by the current constructor: absent or source-falsy rails omit it, while present empty rails emit an empty list. A later imported station-presence state has no separate canonical restore API in this checkpoint.
