`Match::validate_field_project_tick(current_order)` is an additive, read-only admission check. Call it before changing the clock, with the complete current unit collection in the caller's actual turn order. It checks ordinary Conquest mode, clock and project-counter capacity, canonical member/job projections, paid descriptors and normalized waiting Join rows. It reserves cached crew capacity for distinct potential waiting members outside the twentieth-tick recount. It does not update sight, recount, charge, draw randomness or mutate queues. Other terrain, combat and runner admission remains with the common tick providers.

The supplied list validates current membership; it is not a captured turn list. If an accepted early producer adds actors, the per-unit pass must use the resulting current collection. The helper does not create a second scheduler or retain another project/job store. A stale queued project number remains a valid waiting row whose later command receives the source's Blocked denial; a malformed New intent or non-singleton row is a representation error.
