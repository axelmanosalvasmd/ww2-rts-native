# Native World startup

`Match::new_world` takes a validated `AuthoritativeMap`, World options and the generator's retained `MatchRandom`. The caller generates and validates the map explicitly. Ordinary `Match::new` continues to refuse World geography so it cannot discard the generator's random history or substitute Conquest setup.

The constructor publishes HQs, neutral bases and guards, forts, then commander Engineer and rifle squads in source order. It retains source guard placement, stable distance ties, occupied-cell checks and the 4,000-cell fort placement search. Guard-base metadata stores resolved region indices; source adapters read the preserved ID from `geography.regions[index].id`, including signed, nonconsecutive IDs. Mutable region team, progress and capper belong to `WorldRuntime`; immutable coordinates, bounds, kinds, names, membership and biome labels remain in `World.geography`. Currency belongs to `start.economy`, production queues to `ProductionState`, and units, health and spatial indexing keep their existing canonical owners.

The local defender uses internal owner `0xffff_ffff`, separate from commander seats, wallets, research and competitive results. Source owner `-1` is converted only by explicit adapters. `WorldActorView` borrows commander facts or the local actor's faction, spawn and visibility. The shared publication guard admits this owner only in actual World mode; every other invalid owner remains an error. Guards use canonical `UnitControl.guard_home`, disabled ability/retreat switches and `Game::Unit.hold_pos`. New World units apply the source's paid-ability autocast restriction.

The final startup vision pass initializes commander visibility, per-team remembered building rows and the local defender's ordered visible-unit set. This does not collect World terrain memory, create a client projection or authorize full terrain publication. No terrain recipient is registered by this constructor. A future World recipient producer must supply remembered rows, mine knowledge, ordered changes and journal history to the existing knowledge-routing component. Ordinary observed memory cannot replace that producer.

Rail setup reads explicit map metadata before startup footprints change terrain. It preserves stations and lines, bridge cells, direction bits, repeated-key behavior and track/station/yard insertion order. Yard cells retain the source's signed, unclipped linear indices, including off-map and row-wrapped values. A nonadjacent line hop produces no direction bits. Departure timers start empty. Native validation rejects malformed rail shapes, fractional or out-of-range references and invalid cells before returning a match; the source does not validate this metadata defensively. Route choice, boarding, trains, departure scheduling and explored rail delivery remain separate.

The first constructor boundary requires logistics disabled and refuses legacy scenarios and objective lists. With logistics disabled the source creates no physical reserve or convoy state. Logistics-enabled World startup needs its regional float32 supply graph, live armed-team occupancy, source stores, actual supply routing and an explicit World recipient terrain producer. The Conquest ground network is not used as a substitute. World command execution, income/capture/defeat/victory phases, firing/combat actor adapters, recovery and server hosting remain outside this startup boundary.

`harness/world-start-fixture.mjs` records the original `createGame` on five explicit inputs: bare and dressed Huge/Massive maps and a crafted open map with nearby defenders, changed home-team hints, repeated rail keys and a skipped nonadjacent hop. It pins x64 Node 24.21.0 and rejects a wrong reference commit or tracked dirty source. The records contain 2,761 initial units, terrain fingerprints and ordered logs, regions, currencies, actor visibility, remembered buildings and rail state. Native fixture comparison, generator-to-startup replay and malformed-input tests are the acceptance checks. Native results are pending until the shared Cargo checks run.
