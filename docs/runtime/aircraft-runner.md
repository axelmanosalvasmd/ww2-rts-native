# Ordinary aircraft and support tick integration

The single `Match::advance_tick` runs represented ordinary Default/Conquest aircraft and canonical off-map support. It has one recorded command boundary, one simulation clock and one path scheduler. Canonical Game owns aircraft pose and strike timing; Aviation, Firing, Combat, Ability and Recovery retain their existing metadata ownership.

Before dispatch, the caller validates the queued boundary, complete current aircraft state, support phase context and exact support cooldown/team bindings. After dispatch, Game still has the old clock while the queue has advanced. State-only aircraft admission and support validation run again before prior poses and the clock increment. These two aircraft guard methods have different queue semantics.

Each live unit prepares its early orders and source building gate. Aircraft consume their actual turn and continue before ordinary riding, suppression and ground timers, work, movement and firing. The late unit list is captured after the live unit loop and before separation. Projectiles run first, then canonical strikes, one Aviation anti-air pass and one cover/cooldown decay. Radio ownership is read before the later point update. Generic retirement retains singular story and lifecycle callbacks.
